# C++ Object-Oriented Programming (OOP) Collection

A comprehensive repository containing C++ source code implementations that demonstrate the core concepts, principles, and pillars of **Object-Oriented Programming (OOP)**.

## 🚀 Core OOP Pillars Covered

This repository includes practical examples of the four fundamental pillars of OOP:

* **Encapsulation:** Binding data and methods together into classes while restricting direct access using access specifiers (`public`, `private`, `protected`).
* **Abstraction:** Hiding complex implementation details and showing only the essential features using abstract classes and pure virtual functions.
* **Inheritance:** Creating new classes (derived) from existing classes (base) to re-use code efficiently (Single, Multiple, Multilevel, and Hierarchical inheritance).
* **Polymorphism:** Allowing objects to take on multiple forms. Covered via **Compile-time** (Function & Operator Overloading) and **Runtime** (Virtual Functions & Overriding) polymorphism.

## 🛠️ How to Use This Code

All code files in this repository are written as **standalone, independent programs**. You do not need to clone the entire project to run them.

1. Browse the folders and open any `.cpp` file you want to test.
2. Click the **Copy** icon in the top-right corner of the code block on GitHub.
3. Paste the code into **any IDE that supports C++** (such as VS Code, CLion, Code::Blocks, Dev-C++, or Xcode).
4. Save the file and hit **Run/Compile**.
